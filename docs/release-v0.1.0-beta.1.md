# Tibo Reset Mailer · v0.1.0-beta.1

首个公开测试版本：把 Tibo 的明确 Codex 重置公告整理成中文邮件，先显示北京时间，再显示美国洛杉矶时间。

## 使用方式

下载源码，按 README 配置自己的 SMTP，运行 `python -m tibo_mailer run`；默认每小时检查。支持 Docker Compose 持久化部署。

## 本版内容

- 核验官方 X 公开页面的作者、正文、原帖链接与明确发布时间。
- 默认保守规则判断，可选自己的 OpenAI 兼容模型接口生成摘要。
- 区分预告、截止时间和完成确认；PST/PDT 歧义显示说明与未经确认的备选解释。
- 一次性部分历史汇总、按帖子正文版本去重、失败优先重试。
- SMTP 结果未知时暂停自动重发，提供人工核对与处理命令。
- 中文教程、英文简介、脱敏邮件截图与 HTML 预览、配置向导和诊断命令。

## 验证范围

- 本地 Windows / Python 3.12：31 项测试通过。
- 真实 X 公开页面 dry-run 成功，读取 7 个当前可见帖子版本并识别出 1 组重置预告；未发送邮件。
- 邮件 HTML 已在浏览器检查，Python wheel 可构建。
- CI 包含 Windows/Linux 测试与 Docker 构建；具体结果请查看仓库 Actions。
- 真实 SMTP 授权登录与可选模型 API 需要使用者自己的凭据；本地使用可控替身测试，没有宣称已通过真实服务端投递验证。

## 已知限制

公开 X 页面只提供部分历史，访问条件及结构可能变化。规则模式可能漏掉复杂语义。GitHub 托管的是源码，首版云端工作流仅做测试和无邮件的来源检查，长期监测需要自己的常开电脑或服务器。此项目监测公开公告，不查询个人账户额度。
