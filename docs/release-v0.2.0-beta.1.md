# Tibo Reset Mailer v0.2.0-beta.1

现在可以把项目链接和自己的收件邮箱发给 Codex，由它配置个人提醒。

## 使用方法

复制 README 的“把这段话发给自己的 Codex”指令，替换收件邮箱。Codex 会阅读 AGENTS.md 和 CODEX_SETUP.md，检查环境、现有提醒、邮箱连接和定时能力，完成安装、实时来源验证、首次汇总与每小时提醒。支持的已连接邮箱可直接发送，不需要手填 SMTP 或另配模型 API Key。

## 新增内容

- Codex 部署入口、可复制的人类指令和每轮执行说明。
- `agent init / scan / prepare / complete`，提供核验过的公开证据、去重、时区转换和待发邮件。
- `agent begin / confirm / failed / status`，保存服务端邮件 ID、恢复待发记录，对未知结果暂停自动重发。
- 独立的私有数据目录、收件人隔离与扫描时效校验。来源失败、幻造时间、过期扫描均不会推进处理状态。
- 原有独立 SMTP 运行方式继续可用。

## 验证与边界

- 44 项本地测试通过，包含完整的 agent 准备、发送前预留、回执确认、初始化和防重复恢复流程；实际邮件工具在此流程测试中以替身代替。
- 实时 agent CLI 抓取在本地验证，未额外向任何用户发送测试邮件。
- 特定 Codex 环境的邮箱连接和定时能力不相同，需要安装时实测。缺少能力时报告“待完成”，不能宣称部署成功。
- 本地任务需要电脑开机联网、桌面宿主保持运行。此版本不提供公共订阅网站，也不承诺 GitHub 云端能直接读取 X。
- 现有 JSON 或其他 SMTP 数据目录不会自动迁移成 agent 状态，避免重复历史提醒。
